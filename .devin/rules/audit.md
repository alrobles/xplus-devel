# xplus development and verification

- This checkout is the private development repository `alrobles/xplus-devel`; the package remains `xplus`, candidate version 1.0.0. The sibling `alrobles/xplus` repository is production. Never synchronize, commit, or push production changes implicitly.
- Run package tests with `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 Rscript -e 'devtools::test(stop_on_failure = TRUE)'`. Inspect FAIL/WARN/SKIP counts. The candidate was checked with R 4.5.2 and glmnet 5.0; a declared older dependency minimum is not evidence that it was tested.
- Run `R CMD build` and full `R CMD check` from a temporary directory outside the checkout, with suggests installed. The package includes `inst/tools` because installed benchmark tests require it; `.devin` and `inst/benchmarks` are excluded from source builds.
- Preserve `inst/benchmarks/numerical-audit` as the 0.1.1 baseline. Candidate diagnostics go to `inst/benchmarks/v1.0.0`: `Rscript inst/tools/audit_core.R inst/benchmarks/v1.0.0` and `Rscript inst/tools/audit_metrics.R inst/benchmarks/v1.0.0`. These scripts report findings rather than serving as CI gates; inspect CSVs. Core accepts an optional second argument pointing to an original PLUS checkout. Its Phylopred integration checks require the sibling repositories.
- Reference: Zhou et al. (2022), doi:10.1371/journal.pcbi.1009956, and `xiaoyulu95/PLUS` (also `zcslab/PLUS`). Distinguish the paper, the authors' source and package extensions. Sampling budgets and smoothing existed in the reference; weighted multiplicity-preserving bootstrap is the new default. `sample_use_time` counts inclusion rounds, not copies within a round.
- `alpha` is the elastic-net mixture; `sigmoid_scale` is separate. Both fitting stages default to deviance. Convergence needs a full window of undamped global residual scores, minimum iterations and sampling coverage; reaching max_iter is not convergence. `learning_rate < 1` still selects global hard-thresholded updates, not a wholly soft iterative estimator.
- Fractional targets `cbind(1-p, p)` are valid: they agree with weighted binary augmentation. Final fallback uses effective class mass in every training fold, not thresholded class counts. `y`/`final_labels` describe actual targets; `pseudo_labels` retain the proposal; `original_y`, fallback metadata, history and counts preserve provenance.
- Prediction aligns named features, respects lambda and accepts positional newx. Single-lambda classes have fixed factor levels 0/1; multiple lambdas preserve a matrix. Metrics reject invalid rows/weights rather than silently omitting them. Undefined AUC is warned NA, not NaN. Finite rank scores may lie outside [0,1].
- The sibling phylopred production release has an independent empty-host-column bug producing Inf/NaN before xplus. Phylopred-devel uses row-specific exclusion. Do not hide or fix that external production bug as part of changes here. Integration can be tested in one R session by loading this checkout with `pkgload::load_all()` and running `devtools::test("../phylopred-devel", stop_on_failure = TRUE)`. On 2026-09-06 it passed 155 expectations but emitted three glmnet CV-path convergence warnings at small penalties; the 11 master fits had jerr=0 and finite selected-lambda out-of-fold predictions. Raising maxit in a diagnostic-only run did not remove those warnings; do not suppress them or claim warning-free integration.
- Legacy tests requiring AUC > 0.5 on noise or requiring some logits outside [0,1] are invalid correctness specifications; use rank/probability identities and explicit signal fixtures. The path benchmark's default is deterministic synthetic data and its training-label metrics are diagnostic, not independent biological validation.
