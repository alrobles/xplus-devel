# Predict from an xplus model

Predict from an xplus model

## Usage

``` r
# S3 method for class 'xplus'
predict(object, newx = NULL, s = "lambda.min", type = "response", ...)
```

## Arguments

- object:

  An `xplus` object.

- newx:

  Optional finite numeric feature matrix; defaults to training data.
  Named training features must match and are reordered automatically.

- s:

  Exact penalty name (`"lambda.min"`, `"lambda.1se"`) or finite
  nonnegative numeric lambda vector. Cache-only objects support only
  `"lambda.min"`. Only applies to the `"glmnet"` backend; other backends
  accept only the default `"lambda.min"`, which is ignored.

- type:

  Prediction type: `"response"`, `"link"`, or `"class"`.

- ...:

  Additional arguments are not supported and cause an error.

## Value

Probabilities (`type = "response"`) or log-odds (`type = "link"`);
cached probabilities of 0 and 1 give infinite log-odds. Classes use a
factor with fixed levels `"0"`, `"1"` for one lambda, or a
dimension-preserving 0/1 matrix for multiple lambdas.

## References

Zhou et al. (2022). doi:10.1371/journal.pcbi.1009956

## See also

[`xplus()`](https://alrobles.github.io/xplus/reference/xplus.md),
[`print.xplus()`](https://alrobles.github.io/xplus/reference/print.xplus.md)
